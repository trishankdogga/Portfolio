# Trishank Dogga — Portfolio

Personal portfolio website built to showcase my technical skills, education, and interests in software development, data analytics, and AI.

The design takes inspiration from futuristic sci-fi environments, using icy blue tones, steel-gray surfaces, subtle lighting, and smooth animations.

## About

I'm Trishank Dogga, a Computer Science undergraduate at Aditya College of Engineering and Technology, graduating in 2028. I'm interested in building software, working with data, and exploring AI-driven applications.

## What's Inside

- Animated hero section with custom SVG artwork
- Sci-fi-inspired cursor and hover interactions
- Scroll animations and atmospheric effects
- Technical skills and education sections
- Space for projects I'll add as I build them
- Contact links for LinkedIn, GitHub, and email
- Responsive layout for desktop and mobile

## Tech Stack

- HTML
- CSS
- JavaScript
- SVG
- Canvas API

## Built With

I used **Claude AI** to help with the website's code and implementation, and **Higgsfield AI** for creative visual exploration.

The animations, layouts, and interactive elements are implemented using frontend code.

## Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Run the HTML file using Live Server, or open it directly in your browser.

No build tools are required for the current standalone HTML version.
